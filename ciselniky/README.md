# Číselníky

`ruian_casti_obci.tsv` – části obcí z RÚIAN (kód, název, obec, kód obce, okres), platné k datu stažení.
Zdroj: ČÚZK, číselníky ISÚI (`UI_CAST_OBCE`, `UI_OBEC`, `UI_OKRES`, https://services.cuzk.cz/sestavy/cis/),
otevřená data pod licencí CC BY 4.0. Obnovení: stáhni a rozbal ty tři ZIPy a spusť
`python3 tools/ruian.py nacti <složka>`.
